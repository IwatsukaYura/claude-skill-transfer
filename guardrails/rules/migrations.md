## 適用状況（リポジトリの外にある事実）

**001 と 002 は本番環境に適用済み。**

適用済みのファイルは編集しない。編集しても本番のスキーマは変わらず、
新しい環境だけが違う定義で作られて、本番と検証環境が静かに食い違う。

変更が必要なときは `003_<変更内容>.sql` を新規作成し、差分だけを書く。

## 列を追加・変更したとき

`src/db/schema.ts` の型と `src/lib/db.ts` のシードを手で同期する。
`tsc` もテストもこのズレを検知しない。

```bash
npm run check:migrations
```

## デフォルト値を変えるとき

`ALTER COLUMN ... SET DEFAULT` は**既存行を変更しない。**
既存行も揃える必要があるなら `UPDATE` を同じマイグレーションに書く。
