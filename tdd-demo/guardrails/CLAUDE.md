# invoice-tdd

請求金額の計算モジュール。仕様は `SPEC.md`。

## コマンド

| 目的 | コマンド |
|---|---|
| テスト | `npm test` |
| 型チェックのみ | `npm run lint` |

## 進め方

**このプロジェクトはTDDで開発する。** `/tdd` スキルを使う。

1. 失敗するテストを1本書く（Red）
2. それを通す最小の実装を書く（Green）
3. 次のテストへ。全部通ったらリファクタ

**先回りして実装しない。** テストが要求していない分岐を書かない。

## 構成

- `src/money.ts` — 金額のヘルパー。**円未満の扱いはここに集約する**
- `src/errors.ts` — `InvoiceError`
- `tests/` — `node:test`。`../src/xxx.js` と `.js` 拡張子で import する（ESM）

## 規約

- `any` は使わない。外部入力は `unknown` で受けて絞り込む
- 端数処理を各所に散らさない。`src/money.ts` の関数を使う
- コメントは日本語

## 環境が強制していること

以下はフックで機械的に止まる。守るかどうかの判断は不要。

- テストが全部通っている状態では `src/` を編集できない（`ask` になる）
- テストが落ちている状態ではターンを終了できない
- `tests/` から参照されていない `src/` のファイルがあるとターンを終了できない
