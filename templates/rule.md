# このパターンに一致するファイルを Claude が「読んだ」ときだけロードされる。
# paths を書かないと毎セッション無条件でロードされる（＝CLAUDE.md と同じコスト）。
#
# ★グロブの規則は2つだけ（v2.1.220 実測。公式ドキュメントの表は誤り）
#
#   ① / を含まないパターン → ファイル名に一致する
#        "*.ts"  は src/handlers/orders.ts にも当たる。ルート限定ではない。
#        つまり裸の "*.ts" を書くと全 TS ファイルで発火し、条件ロードの意味が消える。
#
#   ② / を含むパターン → ルートからのフルパスに固定。* は / を越えない
#        "src/handlers/**/*.ts"  ○  src/handlers/orders.ts
#        "src/*.ts"              ✗  （src/ 直下だけ）
#        "handlers/*.ts"         ✗  （ルートから書かないと当たらない）
#
#   → 実務ではルートから書いて ** を使う。
#
# ★書いたのに発火しない、が最大の失敗モード。しかも静かに失敗する。
#   必ず InstructionsLoaded フックで観測して確認する:
#     tail -f .claude-instructions.log
#   出力に matched glob と triggered by が出る。
#
# ★新規ファイルを作るだけの作業では、既存の一致ファイルを Claude が読まないと
#   当たらないことがある。確実に届けたいなら paths: を外すか hook にする。
paths:
  - "src/api/**/*.ts"
  - "src/**/*.{ts,tsx}"
